# Instruções do modelo header

- Este arquivo é a base do header para a criação de todas as páginas, favor criar outro css para estilizar o body e deixar o nav-style.css apenas para a a estilização do menu.

- Favor criar a pagina a partir da anotação: ```<!-- COLOCAR O CONTEÚDO DA PÁGINA AQUI -->``` e deixar o ``` <script src="./scripts/carregar-componentes.js"></script> ``` sempre no final do documento html.

- Mudar também o <title></title> no novo html pro nome da pagina sendo criada.

- Vamos deixar para editar os 'href' dos links do menu popup pós todas as paginas serem criadas (ou passarmos o projeto para frente), para n correr risco de sobrescrever arquivos no header de modelo.
